# short-drama-prompts

> 小说 → 漫剧（动态漫画）/ 短剧 · 分镜 · 生图 · 视频提示词，端到端流水线。

把一个小说/网文，端到端转成**可直接用于制作**的产出：改编剧本 → 拆分分镜 → 锁定角色/场景/道具/画风四重一致性 → 实生角色三视图与场景图 → 4 格漫画分镜图 → 动态漫画与图生视频**双轨提示词**。

## 解决什么问题

手上有小说想做成漫剧或红果风格短剧，但通常卡在四处：

1. **剧本怎么改** —— 不会把长篇小说压缩成 ≤2 分钟/集、带钩子的短剧结构；
2. **分镜怎么拆** —— 不知道按什么粒度把剧本转成画面；
3. **AI 生图怎么不跑偏** —— 角色会"换脸/换发色/串画风"，前后不一致；
4. **怎么喂给生视频工具** —— 缺能直接用的视频提示词。

本技能把这一整套流程固化成 8 个阶段，按顺序走完即可。

## 主要功能（8 阶段）

| 阶段 | 产出 |
|---|---|
| Stage 0 | 输入接收 + 形态/画风选择（国漫2D / 日漫赛璐璐 / 韩漫条漫，一次锁定） |
| Stage 1 | 内容分析卡：主线、人物关系图、情绪曲线、题材标签、爽点候选 |
| Stage 2 | 爆款对标调研：联网查同题材爆款套路（联网失败用内置规律库兜底） |
| Stage 3 | 小说 → 分集剧本（≤2分钟/集、3秒强钩子、结尾留反转钩子） |
| Stage 4 | 资产抽取 + 一致性手册 + 实生设定图（角色三视图 / 场景图 / 道具图） |
| Stage 5 | 剧本 → 分镜（按 10 秒/段切分，不删减剧情） |
| Stage 6 | 4 格漫画分镜图（故事板 + 实生图） |
| Stage 7 | 双轨视频提示词（轨A 图生视频 / 轨B 动态漫画） |
| Stage 8 | 四项一致性校验 + 最终交付 |

核心约束：**全剧只允许一种画风**，角色/场景/道具第一次定义后锁定为「ID + 锁定描述 + 实生设定图」，后续只引用、不重写外观。

## 安装方法

这是一个标准 `SKILL.md` 格式的技能，把整个目录复制到对应 AI 工具的 skills 目录即可：

| AI 工具 | 技能目录 |
|---|---|
| WorkBuddy AI | `~/.workbuddy/skills/` |
| Claude Code | `~/.claude/skills/` |
| Codex CLI | `~/.codex/skills/` |
| Cursor | 项目内 `.cursor/skills/` |

`references/` 目录必须一并复制（画风预设库、一致性手册、交付模板、爆款规律库都在里面）。

## 使用方法

把小说交给 AI，触发本技能即可，例如：

> 把这篇小说改编成漫剧

技能会按 8 个阶段自动推进，只在关键决策点停下来问（如画风选择、是否实生图）。**不想实生图时**说「只出提示词，不出图」即可跳过生图环节，只拿提示词。

## 输入输出示例

**输入**：一篇玄幻小说章节（文本或文件）。

**输出**：

1. 画风声明 + 剧名 + 人物角色表 + 场景信息表
2. 实生图产物清单（角色三视图 / 场景图 / 4 格分镜图，含文件路径）
3. 分镜总表（按「集 → 10 秒段」展开）：

| 章节剧本内容 | 分镜图提示词（4格漫画） | 分镜图（实生图） | 视频提示词（双轨） |
|---|---|---|---|
| 【剧本原文/动作/台词】 | `[4-panel comic storyboard]...` | `[分镜图路径]` | 轨A 图生视频 / 轨B 动态漫画 |
