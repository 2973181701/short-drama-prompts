# 红果爆款短剧结构规律（兜底规律库）

当无法联网获取真实爆款样本时，按本库规律设计剧本与节奏。

## 一、单集节奏（≤ 2 分钟）

| 时间 | 段落 | 任务 |
|------|------|------|
| 0 - 3 秒 | 黄金开场 | 强钩子：冲突 / 悬念 / 反差（耳光、逆袭宣言、身份误会、死亡威胁） |
| 3 - 30 秒 | 铺陈 | 快速交代人物关系与矛盾，不废话 |
| 30 - 90 秒 | 冲突升级 | 1 至 3 个冲突点，情绪往上推 |
| 90 - 110 秒 | 爽点 / 反转 | 打脸、身份曝光、实力碾压、真相揭晓 |
| 110 - 120 秒 | 结尾钩子 | 留悬念 / 新反转 / 未解危机，逼观众看下一集 |

## 二、反转密度

- 身份曝光（废柴其实是战神 / 总裁）
- 误会解除（错怪女主 → 真相打脸）
- 实力碾压（被轻视 → 展现实力 → 全场折服）
- 每集至少 1 个反转，爆点集可 2 个。

## 三、人物标签化（便于打脸）

- 男主：战神 / 总裁 / 神医 / 赘婿（前期被踩，后期碾压）
- 女主：重生 / 逆袭 / 带娃 / 豪门弃妇
- 反派：脸谱化（势利眼、恶婆婆、白莲花），负责被反复打脸
- 配角：工具人（助攻或搞笑）

## 四、爽点公式

被轻视 → 展现实力 → 全场打脸 → 收获崇拜 / 逆袭。

## 五、台词与情绪

- 台词短狠、信息密度高，少用长句和旁白。
- 情绪极端快速切换：爽、怒、虐、甜。
- 高频爽词：「你算什么东西」「跪下」「我不是你能惹的人」。

## 六、常见题材

战神归来、总裁娇妻、重生逆袭、豪门恩怨、神医赘婿、疯批追妻、替嫁新娘。

## 七、与改编的衔接

- Stage 3 改编时，把小说主线映射到上述「爽点公式」与「反转节奏」。
- 若小说本身无强冲突，则在保留主线前提下，前置一个钩子冲突（如误会、危机）来起集。
