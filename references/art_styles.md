# 漫剧画风预设库（Art Style Presets）

> 漫剧是「画出来的短剧」，画风是全剧最顶层的锁。**全剧只允许一种画风**，从第一张角色设定图到最后一张分镜图，所有生图 prompt 都必须带同一组「画风关键词」。画风一旦在 Stage 0 选定，全程不可变。
>
> 本库定义三种画风预设 + 自动匹配规则。做 Stage 0 画风选择、Stage 4 设定图、Stage 6 分镜图前必读。

---

## 画风选择规则（Stage 0 执行）

1. **用户显式指定** → 以用户为准，写入一致性手册「画风锁定」。
2. **用户未指定** → 按题材自动匹配：
   - 玄幻 / 修仙 / 战神 / 古装权谋 / 男频爽文 → **国漫2D**
   - 二次元 / 恋爱 / 校园 / 异世界 / 奇幻冒险 → **日漫赛璐璐**
   - 言情 / 霸总 / 都市情感 / 重生逆袭 / 悬疑都市 → **韩漫条漫**
3. 匹配结果必须明确告知用户并让其确认，不静默决定。

---

## 预设一：国漫2D（Chinese 2D Donghua）

**定位**：国漫动画质感，色彩浓烈、戏剧化光影，适合男频玄幻/修仙/战神。

- **画风关键词（所有生图 prompt 必带，英文利于生图模型识别）**：
  `Chinese 2D donghua style, vivid saturated colors, clean bold lineart, cel shading, dramatic rim lighting, highly detailed character design, chinese fantasy aesthetic`
- **中文基线描述**：国漫2D动画风，色彩饱和浓烈，线稿干净利落，赛璐璐上色，轮廓光强，角色设计精致，中式幻想美学。
- **角色锁脸要点**：男性主角多为「剑眉星目、轮廓硬朗、下颌线分明」；女性「明艳大气」；上色用高饱和暖色（红/金/玄黑），光影对比强，常带轮廓光。
- **配色偏好**：主色浓墨重彩，金/红/黑/青，避免日式粉嫩淡彩。
- **推荐尺寸**：竖屏 9:16 用 `1024x1536`；三视图横版用 `1536x1024`。

---

## 预设二：日漫赛璐璐（Japanese Anime Cel-shaded）

**定位**：日系动漫赛璐璐，细线稿、明快平涂、大眼萌，适合二次元/恋爱/校园。

- **画风关键词**：
  `Japanese anime style, cel shading, clean thin lineart, bright flat colors, large expressive eyes, soft gradient shading, anime screencap aesthetic, detailed anime background`
- **中文基线描述**：日系动漫风，赛璐璐上色，细线稿，明快平涂，大而有神的眼睛，柔和渐变阴影，动漫截图质感，背景细腻。
- **角色锁脸要点**：眼睛是核心识别位（形状/瞳色/高光位置必须锁定）；发色可夸张（粉/蓝/银/渐变），但一经锁定不可换；表情夸张化（Q版感、颜艺、脸红）。
- **配色偏好**：明快高亮平涂 + 柔和渐变阴影，允许夸张发色/瞳色。
- **推荐尺寸**：竖屏 9:16 用 `1024x1536`；三视图横版用 `1536x1024`。

---

## 预设三：韩漫条漫（Korean Webtoon）

**定位**：韩漫条漫，半写实精致上色、氛围光影，适合言情/霸总/都市情感。

- **画风关键词**：
  `Korean webtoon style, polished semi-realistic rendering, soft cel shading, refined lineart, atmospheric lighting, elegant character design, vertical scroll comic, cinematic color grading`
- **中文基线描述**：韩漫条漫风，半写实精致上色，柔和赛璐璐，线条细腻，氛围感光影，角色设计优雅，竖屏条漫，电影级调色。
- **角色锁脸要点**：半写实五官精致，男性「窄脸、长眼、高鼻梁、下颌收紧」，女性「精致美艳」；上色柔和、低饱和高级灰 + 局部强调色；氛围光（窗光/逆光）是韩漫标志。
- **配色偏好**：低饱和高级色调 + 氛围光，避免国漫式浓烈、日漫式平涂。
- **推荐尺寸**：竖屏 9:16 用 `1024x1536`；三视图横版用 `1536x1024`。

---

## 画风锁定的三条硬规矩

1. **一处定义，处处引用**：画风关键词只在一处定义（一致性手册「画风锁定」），后续所有生图 prompt 直接粘贴同一组关键词，不得改写、增删。
2. **禁止混风**：一张图里不得同时出现两种画风特征（如韩漫脸 + 日漫大眼睛）。生图后若发现串风，立即在 prompt 里补强调该画风关键词重生成。
3. **换风 = 全部重来**：若中途想换画风，已生成的角色/场景/分镜图全部作废重生成，因为画风变了人物就「不是同一个人」。所以 Stage 0 选风必须慎重、一次到位。

## 与生图尺寸的对应

| 用途 | 推荐 size | 说明 |
|------|-----------|------|
| 角色三视图设定图 | `1536x1024`（横） | 左正面 / 中侧面 / 右背面 三格并排 |
| 场景设定图 | `1024x1536`（竖） | 漫剧为竖屏，场景按 9:16 构图 |
| 道具设定图 | `1024x1024`（方） | 单品特写 |
| 4 格分镜图 | `1024x1536`（竖） | 竖排 2x2 或上中下三格+一格，适配竖屏观看 |
